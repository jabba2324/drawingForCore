## drawingForCore 0.2.0

drawingForCore now targets **.NET 10 LTS** (`net10.0`), as webForCore does from its 0.7.0. 0.1.0 targeted .NET 11 RC
(`net11.0`). A `net10.0` package also works in .NET 11 applications, so 0.1.0's users can move to 0.2.0.

- **Packages:** `drawingForCore.Common` (System.Drawing.Common 11.0.0.0) and `drawingForCore` (System.Drawing 13.5.0.0),
  with the same assembly identities as 0.1.0.
- **No code changes:** the lifted source and the GDI+ engine are the same as in 0.1.0. Only the target framework and
  the SDK changed.
- **Tests:** Microsoft's System.Drawing.Common 6.0 suite on .NET 10, the same results as on .NET 11: 3,882 tests in CI
  on Linux and on Windows, 3,705 pass, 26 skipped (10 of them need an installed printer), 151 known failures (141 are
  metafiles).
- **The NuGet feed:** `https://jabba2324.github.io/drawingForCore/index.json` keeps the latest five releases, so 0.1.0
  stays available there too.

Known limitations: metafiles (EMF/WMF) aren't implemented, and macOS isn't tested. See README.md.
